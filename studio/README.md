# 星图书房

《落星传音》的桌面写作工作台（Electron + React）。管剧情线、人物、地点、世界脉络和伏笔，并在写每一章之前生成“写作上下文”，让 Claude 照着已有设定写，而不是凭记忆写。

## 运行

```bash
cd studio
npm install
npm run build   # 打包界面和主进程
npm start       # 打开桌面窗口
```

- `npm run dev`：开发模式，改代码热更新。
- `npm run web`：只在浏览器里预览（http://127.0.0.1:5199），读写的是同一份数据。
- `npm run dist`：打包成 Windows 便携版 exe，输出到 `studio/release/`。

不开界面也能用命令行（写章节时 Claude 就是这么用的）：

```bash
node studio/scripts/cli.mjs context 31   # 生成第 31 章的写作上下文 → story/context/chap31.md
node studio/scripts/cli.mjs guard 31     # 检查第 31 章；不带章号检查全部
```

打开软件先看到**书架**：一本书一个封面，点封面进入那本书，点标题栏的“书架”或左上角的“星图书房”回到书架。书架上可以“新建一本”（在选定的目录下建一个以书名命名的文件夹，放好 bible.md、outline.md、progress.md、CLAUDE.md、chapters/ 和 story/），也可以把已有的小说目录放上来；从书架上拿下来只是不显示，不删文件。每本书的数据都在自己的目录里，互不相通。书架的书目记在软件的用户目录（config.json），不进仓库。

命令行默认处理 studio 的上一级目录；处理别的书要加 `--root <那本书的目录>`。

## 手机版

手机上看书、查人物、伏笔和设定（只读，离线也能看）。电脑上改完，手机连同一个 Wi-Fi，点一下“同步”就把书架上所有书的改动拉过去，只拉改过的文件。

- **桌面端**：星图书房开着就开着同步服务（HTTP 5210、UDP 5211 应答手机的广播）。标题栏的“手机”按钮里有二维码、配对码，也可以关掉。第一次开启时 Windows 防火墙会问，选“专用网络”并允许。
- **安卓 App**：`npm run apk` 打包（需要 Android Studio），输出 `release/xingtu.apk`。桌面端开着时手机扫“手机”面板里的二维码，打开的页面上有下载链接。App 里点“同步”会自动找到电脑，第一次输入配对码。路由器拦了广播的话，点“手动输入电脑地址”。
- **iPhone / 没装 App**：扫码直接用网页版（配对码在码里）。网页版是电脑发过来的，电脑关了就打不开。
- **阅读**：点屏幕中间呼出菜单。“设置”里能换字体、底色、字号、行距、段距、字距、边距和**翻页方式**：上下滚动、左右平移、覆盖、无动画。后三种一页一页翻，点屏幕左右两边或左右划翻页，翻过本章头尾就到相邻的章；换翻页方式时停在原来读到的位置。
- `npm run mobile`：在浏览器里调手机端界面（http://localhost:5299）。
- 不开界面只开同步服务：`node studio/scripts/cli.mjs serve [配对码] [其他书目录...]`。

手机端源码在 `mobile/`（React，和桌面端共用 `shared/` 与 `src/lib/` 的纯函数），安卓工程在 `mobile/android/`（Capacitor），自动发现电脑的 UDP 广播是 `DiscoveryPlugin.java`。同步协议见 `shared/sync.ts`。

## 数据放在哪

分工：**世界观和规则**只写在 `bible.md`；**人物、关系、地点、伏笔、剧情线、章节规划**只写在 `story/`。软件“设定”页里的条目按小节标题引用 `bible.md`，显示的永远是 bible.md 的最新内容；点“在原文中编辑”会跳到 bible.md 的那一节。

`story/` 在仓库根目录下，一个集合一个 JSON 文件，可以直接用 git 看改动，Claude 也能直接读：

| 文件 | 内容 |
| :--- | :--- |
| `project.json` | 书名、时代、章节类型（今/古/亭）、卷、阶段、关键日子、守卫设置 |
| `chapters.json` | 每章的计划、实际梗概、故事时间、状态 |
| `plotlines.json` / `beats.json` | 剧情线和网格里的卡片 |
| `characters.json` / `relations.json` | 人物档案、按章推进的状态变化、人物关系 |
| `locations.json` | 地点，古今对照，地图坐标 |
| `events.json` | 世界脉络：历史、故事事件、古今痕迹 |
| `foreshadows.json` | 伏笔 |
| `codex.json` | 设定条目：多数是对 `bible.md` 小节的引用（`source`），“写作必带”的会进写作上下文 |
| `context/chapNN.md` | 生成的写作上下文 |

正文仍然是 `chapters/chapNN.md`，软件里改正文就是改这些文件。软件开着的时候，外面（比如 Claude 在终端里）改了这些文件，界面会自动同步。

## 各页面

- **书架**：首页，所有的书摆在木架上，封面下是已写章数、字数、进度和最近改动。
- **总览**：进度、字数、下一章、守卫提醒、人物出场热力图。
- **剧情线**：Plottr 式网格，横轴章节、纵轴剧情线，卡片可拖动。
- **章节**：正文编辑器（人名、地名、套话高亮），右侧“本章雷达”列出出场人物、地点、剧情卡、伏笔和守卫问题。
- **人物**：档案 + “写到第 N 章时的状态”（随剧情推进自动叠加）+ 力导向关系图（古今分两侧）。
- **地点**：宗门地图，可切换古代 / 现代 / 古今对照，拖动调整位置。
- **脉络**：万年长河（世界历史）、故事日历（古今两条线按天并排）、古今交汇（古今痕迹）。
- **伏笔**：弧线图，从埋下的章连到计划收的章，逾期标红。
- **设定**：设定条目和仓库里的 markdown 文档。“写作必带”的条目会进写作上下文。
- **守卫**：扫描全部正文，查配角出圈、古今地名混用、提前登场、伏笔逾期、时间倒流、套话。

快捷键：`Ctrl+K` 搜索一切，`Ctrl+1…9` 切换页面，`Ctrl+Z` 撤销，`Ctrl+S` 保存正文。顶栏的“写到第 N 章”决定人物状态、关系按哪一章计算。
