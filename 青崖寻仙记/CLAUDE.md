# 青崖寻仙记

古风修仙小说，照游戏《青崖寻仙记》第一、二幕改写：孤儿许安在落霞镇过了一天，被土地庙里的老道云鹤子收为徒弟；七天后师父想夺他的身子，到了那一夜却在门外坐到天亮，自己死了。许安接下破观和三十块灵石的债，三个月里收了四个无处可去的人，撑到收债日。

## 文件

- `bible.md`：设定集，世界观和规则的唯一来源
- `outline.md`：大纲（两卷都细到章）
- `progress.md`：写作进度、已写章节
- `chapters/`：正文，每章一个文件 `chapNN.md`
- `story/`：桌面软件“星图书房”的结构化数据，人物、关系、地点、伏笔、剧情线、章节规划的唯一来源

工具在上一级目录的 `studio/` 里，处理这本书都要加 `--root`（在 novel666 根目录下运行）：

```bash
node studio/scripts/cli.mjs context N --root 青崖寻仙记   # 生成第 N 章写作上下文 → 青崖寻仙记/story/context/chapNN.md
node studio/scripts/cli.mjs guard N --root 青崖寻仙记     # 检查第 N 章；不带章号检查全部
```

## 写作规范

流程照 `../.claude/skills/novel-writer/SKILL.md` 的“开写前”“写完自检”“写完同步”走（落星亭、墟、紫气那些是《落星传音》的设定，这本书没有）。下面是这本书自己的规矩，和那份冲突时以这里为准。

### 篇幅和格式

- 一章 2600–3200 字，2–3 个场景，用 `---` 分开。开头 `## 第N章：标题`，每卷第一章再加 `# 第X卷：卷名`。
- 第一卷每个场景开头点一下时辰（“辰正”“未初”），读者能跟着一天往下走。第二卷用“当观主的第几天”或节令交代日子，不写阿拉伯数字。
- 对白用“”。

### 视角和口气

- 第三人称，紧跟许安。别人的心思只写许安看得见、听得见的。第二卷拜师七天尤其要守住：师父在想什么，只能从他的动作和半截话里漏出来。
- 叙述平实克制，带一点冷。笑点放在人物和处境里（小顺子、狗蛋、阿蛮挖宝、贾半仙说书、赌坊里用神识看骰子），不放在旁白的俏皮话里。
- 情绪到顶的时候接一个低调的细节收住，不煽。

### 文风

- 不要拟人化的修辞：火、灵气、泉、香、风照实写它们怎么样。
- 先写看见、听见、闻见、摸到的，再让人物判断。
- 对白要像人说话：带语气词、连接词、半截的补充。短句只在顶嘴、吓着、不想多说的时候用。游戏里的台词能用就用，但要改成连贯的说话，不要照搬选项口吻。
- 段落：叙述不要一句一段，短句并进前后段落。
- 停顿（“没说话”“过了很久”“好一会儿”“顿了顿”）每章合计不超过三处（守卫会数）。
- “不是 X，是 Y”每章最多两次。少用：倒吸一口凉气、脸色一阵青一阵白、陷入了短暂的沉默、翻了个白眼。
- 钱数写清楚，按 `bible.md` 2.4 的价。数字写汉字。
- 人物的穷、病、残缺交代一次就够，不反复拿来说事。
- 结尾停在动作、对白或画面上，不写感悟、不总结、不预告。

### 人物

- 许安：十六岁，南边破庙长大，讨饭北上。手脚快、眼尖、肯吃苦，见过世态，不轻信人，可别人对他好一分他记十分。话少，说出来的多是实在话，偶尔冒一句破庙里学来的俏皮话。会犯错，会怕。
- 云鹤子：干瘦，咳嗽，爱讲山上的旧事，讲着讲着自己先笑。第一卷只让读者觉得他好；第二卷他的好也是真的，不把他写成伪君子。
- 四个弟子各有口气：小芷爱念叨，叫许安“大哥哥”（上山后改叫“师父”时要有一场）；素弦话少、冷，一句顶别人三句；狗蛋嘴快、机灵、好面子；阿蛮北边口音，直，笑起来不收着。
- 反方要体面：钱满仓是生意人，讲规矩，也有分寸；赵家管家客气得叫人发冷；供奉一句话不说。

### 和游戏的关系

- 剧情照 `outline.md`，台词和细节去游戏源码里查（`src/data/events.ts`、`night.ts`、`act2*.ts`、`src/ui/screens/possess.ts`），能用的照用。
- 游戏的界面说法（好感、判定、时段、神识上限多一格）不进正文，改成故事里的事。
